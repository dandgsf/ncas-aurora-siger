# Colaboração

Use branches curtas por responsabilidade, com testes antes da integração na main.
Preserve cada branch concluída até sua revisão. Commits devem descrever o resultado.

Execute `python -m unittest discover -s tests -v` na raiz. Não inclua credenciais,
dados pessoais, cópias do material didático ou diretórios de outros projetos.
Alterações no formato JSON precisam preservar dados existentes ou oferecer migração.

Documentos de entrega são autorais; exemplos operacionais são fictícios. A autoria
acadêmica e a licença de distribuição deverão ser acordadas pelos integrantes antes
da publicação. Nenhuma licença de terceiros é atribuída ao trabalho da equipe.
